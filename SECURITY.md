# Política de segurança

## Reportando uma vulnerabilidade

Encontrou uma falha que pode prejudicar usuários (por exemplo, um ajuste que desativa uma proteção, ou uma forma de fazer o programa gravar fora do que está previsto)?

**Não abra uma issue pública.** Use o recurso de relato privado do GitHub:
*Security > Report a vulnerability*, na página do repositório.

Responderemos assim que possível e daremos o crédito a quem reportou, se desejado.

## Escopo

O programa roda com os privilégios do usuário e só pede administrador quando o usuário aceita. Os limites do que ele pode fazer estão descritos em [docs/SEGURANCA.md](docs/SEGURANCA.md). Qualquer comportamento fora desses limites é considerado um bug de segurança.
